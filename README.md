## ✨ Features

- 🛍️ **Interactive Product Showcase**: Dynamic product cards with hover previews, discounts, badge labels, and instant add-to-cart.
- 🔍 **Live Search & Filter**: Real-time product search with category selection, price range sliders, and multi-criteria filters.
- 🛒 **Full Cart Drawer & Wishlist**: Off-canvas shopping cart with quantity management, subtotal calculation, coupon code redemption (`CRAZY50`), and saved wishlist items.
- ⚡ **Product Quick View Modal**: Modal popup with detailed image galleries, size picker, fabric details, and stock availability.
- ⏳ **Drop Teaser & Countdown Timers**: Upcoming drop announcements with real-time countdown clocks.
- 📱 **Fully Responsive Design**: Optimized for smartphones, tablets, laptops, and ultra-wide screens with smooth touch navigation.
- 🎨 **Modern Aesthetics**: Rich gradients, micro-interactions, dark/light accents, and smooth CSS animations.

├── index.html                                    # Main storefront & landing page
├── Home.html                                     # Alternative homepage view
